# nice ✨

پروژه‌ای که نشون می‌ده لزومی نداره همیشه از Next.js استفاده کنی.

با HTML خالص + کمی CSS و JS می‌شه چیزهای تمیز و قشنگ ساخت.

**ساخته شده توسط امیرحسین بخشی**

---

## ایده

گاهی وقتا ساده‌ترین راه بهترین راهه.  
این پروژه یادآوری می‌کنه که فریم‌ورک‌ها ابزار هستن، نه الزام.

---

## اجرا

فقط فایل `index.html` رو باز کن یا با یه لایو سرور ساده اجراش کن.

```bash
# مثلا با live-server
npx live-server
```
